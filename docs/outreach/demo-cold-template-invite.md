## 🎯 客户具体画像选择

把邀请信发出去之前，先看看以下 3 类，谁最有可能响应：

| 类型 | 抓痛点 | 邮件切入角度 |
|---|---|---|
| **A. 国内老板（温岭 / 永康 / 临沂一带）** | 海外询盘多到自己 read 不过来，但又没请 1 个外贸员 | "30 分钟帮我看一下您最近收到过什么询盘，免费" |
| **B. 外贸 SaaS / Alibaba 卖家** | 找客户 + 报价 + 邮件是日常重复劳动 | "自动 9 步链路 + 完整 trace JSON + HTML 报告，您看完觉得是不是能加速您" |
| **C. 海外 EPC / 工程公司** | 想快速比对多个中国供应商 | "完整报价 + 让步建议 30 秒就能拿到，您用它给老板拍板" |

**优先级建议**：先发 A 类（温岭老板老板熟人），再尝试 B 类（阿里 SaaS 伙伴群），最后才考虑 C 类（海外熟人）。
